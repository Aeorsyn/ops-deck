## ⚡ What Is This?

This project operates on two integrated tiers:

1. **The Conversational Builder & Agent Core:**  
   An autonomous multi-agent orchestration framework (Forebrain / Core 3000) that interprets natural language instructions, executes continuous environment scouting, and autonomously writes, AST-validates, and hot-swaps working React 18 / Canvas2D components on the fly without restarting the host server.
   
2. **The Tactical Command Cockpit (Client Runtime):**  
   A zero-dependency, in-browser mounting harness that renders real-time telemetry, orbital mechanics, and physics simulations streamed directly from the agent synthesis pipeline.

## 🛠️ Architecture Highlights

- **Dynamic In-Browser JSX Runtime:** Zero Node.js or Vite bundling overhead. Raw component code from the agent is transpiled on-demand via standalone Babel and mounted straight to the DOM.
- **Resilient Component Harness:** Automatically isolates runtime exceptions, mocks missing third-party icon libraries on the fly, and maintains stable telemetry feeds.
- **Engineered for ARM / Edge Deployment:** Runs efficiently in lightweight headless Linux environments (native Debian / PRoot Arch Linux).
